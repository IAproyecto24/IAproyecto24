## 🚀 Proyectos destacados

### 1. Sistema Inteligente de ETL, Monitoreo y Planeación Operativa

Proyecto de grado de maestría orientado al desarrollo de una solución inteligente para integrar datos productivos, estructurar procesos ETL, generar analítica operativa y apoyar la planeación mediante modelos predictivos y recomendaciones.

**Objetivo principal:**  
Diseñar un sistema basado en Ciencia de Datos e Inteligencia Artificial para integrar información de producción, monitorear el comportamiento operativo y apoyar decisiones de planeación en plantas de confección con alta diversificación productiva.

**Componentes principales:**

- Extracción, limpieza y transformación de datos desde archivos empresariales.
- Construcción de base histórica local y dataset de modelado.
- Análisis exploratorio de datos productivos.
- Entrenamiento y evaluación de modelos de Machine Learning.
- Modelo operativo basado en **XGBoost** para detección de riesgo alto/crítico.
- Backend desarrollado con **FastAPI**.
- Frontend web para demo operativa.
- Persistencia local con **SQLite**.
- Arquitectura orientada a Data Mart en **SQL Server**.
- Motor de recomendaciones basado en riesgo predictivo y fortalezas operativas por módulo.
- Enfoque metodológico basado en **CRISP-DM**, estructura técnica tipo **MLOps liviano** y trabajo incremental por fases.

**Tecnologías utilizadas:**  
`Python` · `Pandas` · `Scikit-learn` · `XGBoost` · `FastAPI` · `SQLite` · `SQL Server` · `HTML` · `CSS` · `JavaScript` · `Git` · `GitHub`

En mis proyectos procuro mantener una estructura clara y segura:

- Documentación técnica incluida.
- Archivos de configuración de ejemplo.
- Datos sensibles excluidos del repositorio.
- Modelos entrenados y bases locales protegidos cuando contienen información privada.
- Uso de `.gitignore` para evitar publicar archivos corporativos, bases de datos o credenciales.
